# VSCode Settings

`vscode-settings.json` in this repo is symlinked to `~/Library/Application Support/Code/User/settings.json`. Running `bootstrap.sh` on a new machine gives you your complete VSCode environment automatically — theme, font, formatter config, Emmet, spell check words, and VSCodeVim settings — with no manual reconfiguration.

VSCodeVim is installed via the Brewfile (`vscodevim.vim` extension entry). The settings file enables:

- `vim.surround` — surround plugin
- `vim.ignorecase` + `vim.smartcase` — case-insensitive smart search
- `vim.scrolloff` — scroll context
- Highlighted yank and EasyMotion
- `<C-h/j/k/l>` — window navigation mapped to VSCode's split focus commands

Commentary (`gc`/`gcc`) is built into VSCodeVim and active by default — no explicit setting required.

## The `vs-kubernetes` block

The `vs-kubernetes` section of `settings.json` contains machine-specific tool paths auto-generated by the VS Kubernetes extension. Those paths are regenerated by the extension on first launch. When that happens, they'll appear as a git diff — **do not commit those diffs**.

## Tracking settings changes

When you change VSCode settings via the UI, those changes write directly through the symlink into the tracked file. Run `git diff vscode-settings.json` to review before deciding whether to commit.
